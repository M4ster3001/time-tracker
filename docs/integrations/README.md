# Integrações

As integrações são opcionais; a aplicação básica não depende de credenciais externas. Ative apenas o que sua organização precisa e revise permissões, custos, privacidade e disponibilidade antes de conectar contas ou dados.

- [Google Calendar](google-calendar.md): conexão e importação de eventos.
- [Provedores de IA](ai.md): sugestões e configuração de serviços externos.
- [MCP](mcp.md): ferramentas locais/HTTP, autenticação e limites de OAuth.

Redis e provedores de backup são configurados no backend por variáveis de ambiente; veja [configuração](../getting-started/environment-variables.md) e [operação](../operations/deployment.md).
