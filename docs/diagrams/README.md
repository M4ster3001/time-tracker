# Diagramas

As fontes Mermaid são a referência editável; os PNGs são prévias estáticas geradas para leitura rápida.

| Diagrama | Fonte | Prévia |
| --- | --- | --- |
| Visão de arquitetura | [architecture.mmd](architecture.mmd) | [architecture.png](architecture.png) |
| Ciclo de um lançamento | [time-entry-lifecycle.mmd](time-entry-lifecycle.mmd) | [time-entry-lifecycle.png](time-entry-lifecycle.png) |

Para atualizar as prévias, use `manus-render-diagram arquivo.mmd arquivo.png` ou um renderer Mermaid compatível. Revise visualmente o resultado antes de publicar uma alteração. Veja também [arquitetura](../development/architecture.md).
