# Política de segurança

Use o canal privado **Security Advisories** do repositório no GitHub para reportar vulnerabilidades. Não publique detalhes exploráveis em issues, discussões ou pull requests antes de haver uma correção ou plano coordenado de divulgação.

Inclua a versão/commit afetado, impacto, condições necessárias e passos mínimos de reprodução. Não envie senhas, tokens, dados pessoais, backups ou registros de clientes. Se o canal privado não estiver habilitado no repositório onde você encontrou o código, contate os mantenedores por um meio privado antes de compartilhar detalhes técnicos.

A configuração de segurança depende também do ambiente de quem implanta. Consulte [controles de segurança](docs/operations/security-controls.md) e [privacidade](docs/operations/privacy.md); esses guias não substituem avaliação profissional nem obrigações legais locais.
